# 页面生成Agent测试说明

## 测试文件
- `ppt_with_research_test.go` - 使用真实资源测试页面生成

## 测试目的
验证 `page_generate_agent` 在以下方面的改进：
1. **充分利用研究资料** - 从研究目录读取并融入相关内容
2. **生成final.html** - 确保最终文件始终为final.html
3. **尺寸容错** - 支持10%的尺寸容差（1280x720 ± 10%）
4. **支持更多迭代** - 最多支持16轮迭代优化

## 运行测试

### 方式1：使用脚本
```bash
./run_page_test.sh
```

### 方式2：直接运行
```bash
go test -v -run TestPageGenerateWithRealResources ./ppt/agents
```
