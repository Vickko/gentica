## 📋 内容概览

### 核心世界观
- **索拉里斯星** - 故事发生的星球
- **悲鸣（Lament）** - 改变世界的灾难性事件
- **共鸣者系统** - 能操控频率的人类
- **声骸系统** - 装备和能力系统
- **六大属性** - 热熔、气动、导电、冷凝、衍射、湮灭

### 主要地区
- **瑝珑（Huanglong）** - 东方文化国家，一庭六州体系
- **今州（Jinzhou）** - 边境要塞城市，1.0主要舞台
- **黎那汐塔（Rinascita）** - 西方文化地区，2.0新区域
- **黑海岸（Black Shores）** - 跨国科研组织总部

### 主要势力
- **瑝珑政权** - 正面势力，东方大国
- **夜归军** - 今州守备军（踏白、破阵、伏波三部）
- **黑海岸** - 观测和应对悲鸣的科研组织
- **残星会（Fractsidus）** - 反派组织，追求人机融合

### 时间线
- 前文明时代 → 第一次悲鸣（约100年前）→ 悲鸣战争（新纪元年110年）→ 重建时代 → 当前（漂泊者苏醒）

## 🎨 创作建议

- 保持悲鸣带来的末世氛围
- 利用多元文化并存的设定
- 发挥共鸣者和声骸的战斗系统

- 参考多线叙事结构
- 利用谜团层叠的手法
- 注意势力关系的复杂性
- 平衡主线与支线

### 角色创作

- 利用六大属性系统
- 考虑共鸣者的不同类型
- 注意文化背景的差异
