# 鸣潮剧情概要与重大事件

## 时间线总览

### 前文明时代
- 存在高度发达的文明
- 创造了泰提斯系统等高科技设施
- 为后世留下了大量遗产和谜团

### 第一次悲鸣（约100年前）
- **鸣潮子突然出现** - 可与任何物质融合的神秘物质降临
- **大规模灭绝** - 星球上大部分生命体消失
- **残象出现** - 未知的怪物开始在世界各地出现
- **文明濒临崩溃** - 人类社会几乎毁灭
- **避难计划（推测）** - 人类可能计划升空，建造空间站作为反攻基地

### 悲鸣战争时期（新纪元年110年前后）

**新纪元年103年左右：**
- 岁光（Shorekeeper）被新的地表势力瑝珑发掘

**新纪元年110年：**
- **悲鸣战争全面爆发**
- 人类地表势力装备大规模武器
- 对残象发起反攻
- 各国军队与残象的大规模战役

**战争结果：**
- 人类幸存者联手
- 结束了与异族的漫长战争
- 在陌生的土地上开始重建

### 重建时代（战后至今）
- 人类文明逐步恢复
- 建立新的国家和政权体系
- 共鸣者成为重要力量
- 各势力在新世界中发展

### 当前时代
- 悲鸣仍在持续
- 残象威胁依然存在
- 漂泊者苏醒，开始新的旅程
