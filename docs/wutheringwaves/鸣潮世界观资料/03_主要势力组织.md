# 鸣潮主要势力组织

## 正面势力

### 瑝珑（Huanglong）

**性质：** 国家/政权

**政治结构：**
- 一庭六州体系
- 中央朝廷统治
- 地方州郡分治

**军事力量：**
- 夜归军（主要军事力量）
- 各州镇戍军

**代表人物：**
- 忌炎
- 丹瑾
- 赤霞
- 秧秧
- 白莲
- 桃祈
- 巴尔

**势力特点：**
- 东方文化背景
- 重视防御和稳定
- 与残象长期作战

---

### 夜归军（Night Return Army）

**性质：** 瑝珑的军事组织

**隶属关系：**
- 今州军策府统辖的镇戍军
- 由夜归将军忌炎统率

**组织结构：**
夜归军按职能分为三部：

1. **踏白** - 斥候部队
   - 成员多为共鸣者
   - 负责侦察和情报

2. **破阵** - 前锋部队
   - 成员多为共鸣者
   - 负责进攻和突破

3. **伏波** - 后卫部队
   - 负责防守和支援

**主要基地：**
- **伏波阵前** - 位于中曲台地与荒石高地交界处
- 作为抵御残象入侵的防线

**主要职责：**
- 守卫今州边境
- 抵御残象进攻
- 保护瑝珑安全

---

### 黑海岸（Black Shores）

**性质：** 跨国科研组织

**核心使命：**
- 观测悲鸣灾害
- 预警悲鸣灾害
- 解决悲鸣灾害

**合作关系：**
与索拉里斯星上的大多数国家保持合作

**总部位置：**
- 风暴海中的黑海岸群岛
- 巨大黑色岩石构成
- 泰提斯系统所在地

**组织架构：**

**成员分类：**
- **客卿（Guest）** - 在外部工作的成员
- **执花** - 在总部工作的成员

**人员构成：**
汇集世界各地各领域精英人才

**已知成员：**
- 安可（Encore）- 客卿
- 岁光（Shorekeeper）- 重要成员

**核心设施：**
- **泰提斯系统（Tethys System）**
  - 前文明遗留的高科技系统
  - 与悲鸣观测和应对相关
  - 黑海岸的技术核心

**历史背景：**
- 新纪元年103年左右，岁光被瑝珑发掘
- 后来成为黑海岸的重要人物

**组织特点：**
- 技术先进
- 国际合作
- 精英导向
- 以科学方法应对悲鸣

## 敌对势力

### 残星会（Fractsidus）

**性质：** 敌对组织/反派势力

**全称：**
- 拉丁复合词"FRACTSIDUS"
- 日语：残星組織
- 韩语：잔성회

**核心理念：**
- 通过人工诱导共鸣实现人类与残象融合
- 引发"真正的悲鸣"使鸣式复苏
- 认为鸣式不是灾厄，而是人类进化必要的助力

**成员构成：**
前文明遗孤构成

**组织架构：**

**会长：**
- **斯瓦茨洛** - 残星会的最高领导者

**会监（高层干部）：**

1. **弗洛洛**
   - 残星会会监
   - 极具音乐天赋，对悲剧沉迷
   - 居住的村庄曾被毁灭，村民全部成为残象
   - 几百年来一直在寻找将残象恢复成人类的方法

2. **克里斯托弗**
   - 残星会会监
   - 对悲剧沉迷的剧作家
   - 共鸣能力可以一定程度上改变现实

3. **伤痕**
   - 残星会会监
   - 曾在村庄中亲眼看到村长吸取村民生命为他人实现愿望
   - 因试图阻止村长而被其他村民迫害
   - 后加入残星会，以黑羊和白羊的隐喻讲述自己的经历

4. **某残星会会监**
   - 暗中资助稷廷的研究工作

**前成员：**
- **椿** - 曾加入残星会，但觉得残星会无法满足本能，后退出

**疑似相关人员：**
- **漂泊者**（主角）- 据伤痕所说，以前可能也是残星会的一员

**合作人员：**
- **芬莱克** - 隐海修会前任主座
  - 为对抗黑潮使用独裁政策强行让拉古那民众思想统一
  - 暗中和残星会合作建造隐海试验场
  - 后被鸣式蛊惑，被漂泊者击败
  - 为赎罪独自留在隐海试验所清理黑潮
  - 生命最后时刻将那不盖勒二世的提灯交给仇远
  - 最后以幻影形式帮助漂泊者驱散黎那汐塔的大片黑潮，牺牲自己

**终极目标：**
- 引发"真正的悲鸣"
- 使鸣式复苏
- 摧毁索拉里斯世界，或推动全人类共鸣者进化

**技术特点：**
- 机械改造技术
- 残象声骸与人类耦合
- 人工诱导共鸣
- 造匠技术（重锤造匠、枪肢造匠、枭面造匠）

**行动方式：**
- 被称为"残星门徒"的下级成员在各地活动
- 进行各种破坏和实验活动
- 在索拉里斯各地存在活动据点

**武装力量：**
- 残星·重锤造匠
- 残星·枪肢造匠
- 残星·枭面造匠
- 处刑人

**组织威胁：**
- 对现有人类文明构成严重威胁
- 技术路线与主流相悖
- 意识形态极端
- 认为鸣式是人类进化的助力而非灾厄

**剧情地位：**
- 主要反派组织
- 贯穿主线剧情
- 2.0版本仇远角色涉及残星会剧情重大进展
- 2.5版本弗洛洛角色深入探讨残星会成员背景

## 势力对比

### 军事力量排名（推测）

**第一梯队：**
- 瑝珑（拥有完整的军事体系和众多共鸣者）
- 黎那汐塔（教会势力强大）

**第二梯队：**
- 新联邦（信息有限）
- 七丘（信息有限）

**特殊势力：**
- 黑海岸（非军事组织，但技术先进）
- 残星会（非正规军队，但威胁巨大）

### 科技水平排名（推测）

**第一梯队：**
- 黑海岸（拥有泰提斯系统等前文明科技）

**第二梯队：**
- 残星会（掌握人机融合技术）
- 瑝珑（常规科技发达）
- 黎那汐塔（神秘学与科技结合）

### 影响力排名（推测）

**全球影响：**
- 黑海岸（跨国合作组织）

**区域影响：**
- 瑝珑（东方大国）
- 黎那汐塔（西方势力）
- 新联邦（待确认）

**破坏影响：**
- 残星会（恐怖主义性质）

## 势力发展趋势

### 合作趋势
面对悲鸣和残象的持续威胁，各正面势力倾向于：
- 通过黑海岸平台加强合作
- 共享悲鸣观测和应对技术
- 联合对抗残星会

### 冲突趋势
- 各国仍保持独立主权和利益
- 文化差异导致潜在摩擦（如漂泊者与黎那汐塔教会）
- 残星会持续制造混乱

### 技术竞争
各势力都在寻求：
- 更好地理解和利用共鸣能力
- 发掘前文明遗产
- 开发对抗残象的新技术

## 组织命名特点

### 东方风格（瑝珑系）
- 夜归军 - 诗意命名
- 踏白、破阵、伏波 - 功能性命名

### 西方风格
- Black Shores（黑海岸）- 英文命名
- Fractsidus（残星会）- 拉丁语命名
- Rinascita（黎那汐塔）- 意大利语"重生"

### 混合风格
- 公安局 - 现代化命名
- 瑞狮会 - 传统命名

这反映了鸣潮世界多元文化并存的特点。
