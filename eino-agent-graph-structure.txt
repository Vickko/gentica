问题: Agent 底层的 Graph 是完全展开的还是压缩的？

答案: 压缩的！

证据:
  1. Graph 只有 4 个固定节点（START, ChatModel, ToolNode, END）
  2. ToolNode 用 map + 数组包含所有 Tools
  3. 运行时通过 map.indexes[name] 动态查找
  4. LLM 在 ToolCalls 中指定要调用的 Tool

本质:
  静态 Graph = 枚举所有路径（空间换时间）
  Agent      = 压缩到 LLM 推理（时间换空间 + 智能）

类比:
  静态 Graph = 有限状态机（显式枚举）
  Agent      = 图灵机（LLM 作为控制器）

优势:
  - 节点数量从 O(2^N) 降到 O(1)
  - 支持任意长度的调用序列
  - 添加 Tool 无需修改 Graph 结构
  - LLM 智能决策调用策略
